## 附：幕布有匿名 API，不必開瀏覽器滾列表

`build/fetch-mubu.mjs` 目前是開 headless Edge、邊滾邊收 DOM（幕布正文是虛擬列表，所以得滾到底）。其實幕布有匿名可讀的 JSON API，一次就回整棵大綱：

```text
POST https://api2.mubu.com/v3/api/explore/get        {"exploreDocId":"…"}   → data.definition（整棵樹）
POST https://api2.mubu.com/v3/api/document/view/get  {"docId":"…"}          → 同上，給 /doc/ 的文件
```

必須帶的 header（缺了回 `{"code":17,"msg":"illegal request"}`）：
`Jwt-Token`（匿名給空字串）、`data-unique-id`、`x-request-id`、`x-reg-entrance`、`x-session-id`（UUID 即可）、`Origin: https://mubu.com`、`Referer`。
